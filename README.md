## 内容怎么来的

每条新闻先由模型按几个方面打分:事情本身多重要、有没有新信息、证据硬不硬、影响面多大、对读者有没有用,过了门槛才进精选。中文总结由 AI 根据原文写,里面的数字会自动和原文核对。原文版权归原作者,每条都附原文链接。详见 [关于与编辑方法](https://aiguanchao.com/about)。
